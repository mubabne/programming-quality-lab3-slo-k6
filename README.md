# Лаборатори №3: Чанарын сценарио → SLO → k6 threshold

- Оюутан: MUNKHBAYAR CHIMEDREGZEN
- Оюутны код: B242270045
- Хичээл: F.CSA313 — Программ хангамжийн чанарын баталгаа ба тест
- k6 version: `k6.exe v2.2.0 (commit/00a9a1b7f5, go1.26.5, windows/amd64)`

Энэ репозиторид зөвхөн локал Express API-г k6-аар туршина. Гадаад сервер рүү load test хийхгүй.

## Локал API

```bash
npm install
npm start
```

Сервер `http://localhost:3000` дээр ажиллана. `/cart/add` нь хурдан, `/report` нь 200–400 мс сааталтай, `/pay` нь хүсэлтийн ойролцоогоор 5%-д 500 алдаа буцаана.

## Чанарын сценарио

| Хэсэг | Performance | Reliability | Availability |
|---|---|---|---|
| Тойм | Сагсанд бараа нэмэх хүсэлт хэвийн ачаалалд хурдан хариулах | Төлбөрийн хүсэлтийн алдааг зөвшөөрөгдөх хэмжээнд барих | Серверийн 10 секундийн зогсолтын үед үйлчилгээг сэргээх |
| Системийн төлөв | API хэвийн ажиллаж, өгөгдлийн сангийн нэмэлт сааталгүй байна | API хэвийн ажиллаж, gateway-ийн санамсаргүй алдаа идэвхтэй байна | API 2 минутын турш ачаалал авч байна |
| Орчны төлөв | Локал машин дээр 20 VU тогтмол ачаалал өгнө | Локал машин дээр 20 VU төлбөрийн хүсэлт илгээнэ | 20 VU гурван endpoint рүү хүсэлт илгээнэ |
| Гадаад өдөөлт | Хэрэглэгч `/cart/add` руу POST хүсэлт илгээнэ | Хэрэглэгч `/pay` руу POST хүсэлт илгээнэ | Тестийн дунд Node.js серверийг 10 секунд зогсоогоод дахин асаана |
| Шаардлагатай хариу | Сервер хүсэлтийг HTTP 200 хариугаар боловсруулна | Амжилттай төлбөрт HTTP 200, gateway алдаанд HTTP 500 буцаана | Сервер дахин асмагц шинэ хүсэлтүүд HTTP 200 хариу авч эхэлнэ |
| Хэмжүүр | 1 минутын турш `/cart/add` latency-ийн p95 < 10 мс, p99 < 20 мс | 1 минутын `/pay` error rate < 8%, амжилттай хүсэлтийн p95 < 10 мс | Нийт хүсэлтийн ≥ 90% амжилттай, сэргэлтийн хугацаа ≤ 12 секунд |

## SLO

| Сценарио | SLI | Босго | Цонх / нөхцөл |
|---|---|---|---|
| Performance | `/cart/add` latency | p95 < 10 мс | 20 VU, 1 минут |
| Reliability | `/pay` error rate | < 8% | 20 VU, 1 минут |
| Availability | бүх endpoint-ийн check амжилт | > 90% | 20 VU, 2 минут, 10 секундийн зогсолттой |
| Нэмэлт performance | `/report` latency | p95 < 450 мс | 20 VU, 1 минут |

`/cart/add` нь локал, тооцоолол багатай endpoint тул 10 мс-ийн p95 босгыг сонгосон. `/pay` кодод 5% санамсаргүй алдаа оруулсан учраас хэлбэлзлийг багтаасан 8%-ийн босго бодитой. `/report` нь зориуд 200–400 мс саатдаг тул 450 мс нь өгөгдсөн зан төлөвийг зөвшөөрөх боловч хэт сул биш босго. Availability SLO 90% тул 2 минутын цонхны цагийн error budget нь `120 × 0.10 = 12 секунд` байна.
