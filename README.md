# Лаборатори №3: Чанарын сценарио → SLO → k6 threshold

- Оюутан: MUNKHBAYAR CHIMEDREGZEN
- Оюутны код: B242270045
- Хичээл: F.CSA313 — Программ хангамжийн чанарын баталгаа ба тест

Энэ репозиторид зөвхөн локал Express API-г k6-аар туршина. Гадаад сервер рүү load test хийхгүй.

## Локал API

```bash
npm install
npm start
```

Сервер `http://localhost:3000` дээр ажиллана. `/cart/add` нь хурдан, `/report` нь 200–400 мс сааталтай, `/pay` нь хүсэлтийн ойролцоогоор 5%-д 500 алдаа буцаана.
